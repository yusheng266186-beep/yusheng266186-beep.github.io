这版重构了什么

  • 从旧式长页面重构为终端式工作台，包含桌面侧栏和移动端底部导航。
  • 首页实时显示 AU9999 国内克价、行情时间、轮询倒计时、数据年龄和最近价格变化。
  • 引入上金所 Au99.99 官方每日历史行情，历史曲线不再由随机数或国际金价换算生成。
  • 新增多周期概率预测、情景锥、因子压力测试、执行框架和综合风险评分。
  • 重做模拟订单、费用、价差、持仓均价、资产配置、止盈止损与成交账单。
  • 新增上金所官方公告抓取与宏观消息降噪，低相关银行执法消息不会占据主要视野。
  • 模型接口与行情链路完全解耦。没有模型 API 时，全部行情、图表、预测、交易和本地建议仍可用。

行情数据怎么工作

用户不需要提供行情数据 API。页面和 GitHub Actions 使用公开行情与官方页面完成自动降级：

1 · 东方财富浏览器尝试直连 AU9999 / Au(T+D)
2 · 新浪 SGE主源失败时切到 SGE_AU9999
3 · 部署快照读取 GitHub Actions 更新的 JSON
4 · 内嵌快照离线双击打开时保证核心界面可用

部署快照在写入前会再与上海黄金交易所官方延时行情交叉校验。公开报价与官方价偏差超过阈值时，脚本会改用官方延时价并记录校验信息。

为什么刷新了，价格可能仍然没变？

页面把“行情时间”和“本次轮询”分开处理。轮询成功只表示获取了最新一笔公开报价；休市、流动性较低或没有新成交时，价格本来就可能保持不变。此时页面会明确显示“轮询成功，价格暂无变化”，倒计时和刷新状态仍会更新。

历史与预测口径

模块数据含义
历史主线上金所 Au99.99 官方每日行情真实开、高、低、收、成交量与成交额快照。
当前盘中点当前 AU9999 国内公开报价以 LIVE 标识追加到历史末端，不伪装成收盘价。
预测带本地因子模型按真实波动率、动量、国内需求、人民币、价差等生成概率区间。
AI 建议可选大模型只负责解释和执行方案，不采集或生成实时价格。

模型接口

在“终端设置”中可以填写兼容 OpenAI Chat Completions 格式的 Endpoint、模型名称和 API Key。默认模型名为 gpt-5，也可以接入其他兼容服务。

安全建议：浏览器直填密钥只适合个人设备测试。商用部署请使用 serverless/openai-proxy-cloudflare-worker.js，把密钥放在服务端环境变量，不要提交进 GitHub 仓库。

GitHub Pages 部署

  1. 新建 GitHub 仓库，把本目录的全部内容上传到仓库根目录。
  2. 进入 Settings → Pages，将 Source 设为 GitHub Actions。
  3. 推送到 main 后，.github/workflows/pages.yml 会部署网站。
  4. refresh-market.yml 每 5 分钟尝试刷新国内行情快照。
  5. refresh-history.yml 在交易日刷新真实历史数据。
  6. refresh-news.yml 每小时刷新官方消息；三个数据任务使用同一并发锁，避免提交冲突。

重要边界

公开网页行情不是券商或交易所授权的逐笔盘口服务，可能有延迟、缓存或临时不可用。本应用适合研究与虚拟交易，不应替代真实交易终端，也不构成投资建议。需要毫秒级推送、五档盘口、真实下单和清算时，必须接入具备授权的数据与交易服务。
