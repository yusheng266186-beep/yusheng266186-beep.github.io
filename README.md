# AURUM OS · 国内黄金决策终端

AURUM OS 是一个面向国内黄金市场研究的浏览器端决策工作台，围绕 AU9999 人民币/克价格，提供行情观察、历史分析、情景预测、风险提示和虚拟交易记录。

> 在线终端：[打开 AURUM OS](https://yusheng266186-beep.github.io/)  
> GitHub：[查看源代码](https://github.com/yusheng266186-beep/yusheng266186-beep.github.io)  
> 使用说明：[README.html](https://yusheng266186-beep.github.io/README.html)

## 项目定位

本项目把“看行情、看历史、做假设、记模拟交易”整合在一个静态网页中。它适合：

- 学习国内黄金报价、波动和影响因素；
- 观察价格历史与多周期情景；
- 记录虚拟买入、卖出、持仓成本和盈亏；
- 练习风险控制、仓位思考和交易复盘；
- 作为金融数据可视化与前端交互项目的演示。

它不是券商交易系统，也不连接真实账户。页面中的买入、卖出和盈亏均为虚拟记录。

## 主要功能

### 国内黄金行情

- 统一以人民币/克展示国内黄金价格；
- 以 AU9999 作为主要价格锚；
- 展示当前价格、变化值、变化比例、行情时间和数据年龄；
- 显示轮询状态、数据来源、校验状态和降级情况；
- 行情源异常时使用缓存、快照或备用来源维持核心页面可用。

### 历史走势与指标

- 使用随项目附带的历史行情数据；
- 查看不同时间范围的价格变化；
- 展示波动率、动量和技术指标；
- 将当前盘中报价与历史序列区分，避免把实时点误当成收盘价；
- 通过图表观察趋势、回撤和波动区间。

### 情景预测

- 支持一周、一个月、半年、一年及更长期的观察框架；
- 生成概率区间和情景带，而不是单一确定价格；
- 综合考虑国内需求、人民币汇率、国际利率、地缘风险、流动性和价格波动；
- 提供因子压力测试、执行框架和综合风险评分；
- 没有大模型 API 时，核心行情、图表、预测和模拟交易仍可使用。

### 虚拟交易

- 模拟买入和卖出；
- 支持不同克重按钮；
- 计算持仓数量、持仓均价、费用、价差和浮动盈亏；
- 保存成交账单和资产配置；
- 支持导出账单和重置模拟账户。

### 官方资讯与自动更新

- 整理上金所官方公告和宏观资讯；
- 通过 GitHub Actions 定时刷新市场快照、历史行情和资讯；
- 对公开行情与官方延时行情进行交叉校验；
- 记录数据更新时间和数据可信度提示。

## 数据链路与降级策略

页面不是只依赖单一行情接口，基本思路如下：

    公开 AU9999 行情
            ↓
    备用公开行情源
            ↓
    GitHub Actions 更新的市场快照
            ↓
    仓库内嵌数据，保证核心界面可打开

部署脚本会在写入快照前进行校验。公开报价与官方延时价出现明显偏差时，系统会优先使用更可靠的官方延时数据，并记录校验信息。

由于交易时段、休市、流动性和数据源更新频率不同，“轮询成功”不等于“价格一定变化”。页面会区分：

- 本次请求是否成功；
- 行情时间是否更新；
- 价格是否发生变化；
- 当前数据是否来自缓存或降级源。

## 使用方式

### 在线使用

直接打开 Pages 地址即可使用核心功能。无需注册，不需要安装 Node.js，也不要求配置大模型 API Key。

### 本地预览

最简单的方式是直接打开 index.html。若要让相对路径、模块脚本和网络请求行为更稳定，可以在项目目录启动静态服务器：

    python -m http.server 8080

然后访问：

    http://localhost:8080/

### 可选模型配置

项目支持可选的 OpenAI 兼容模型接口，用于辅助建议和解释。模型接口不是行情主链路，也不是页面运行的必要条件。

配置模型接口时：

- 只在本地环境配置密钥；
- 不要把密钥写进 index.html、assets/、data/ 或 README；
- 不要提交 .env 或带密钥的日志；
- 将模型建议视为辅助信息，不要把它当成交易指令。

## 维护建议

- 定期检查行情源是否仍然可用；
- 更新快照时保留来源、时间和校验信息；

- 区分实时点、收盘点和预测点；
- 修改模拟交易逻辑后重新测试费用、均价、盈亏和重置；
- 对所有公开接口增加失败、超时和空数据处理；
