# AURUM · 黄金市场档案

以上海金 AU9999 人民币/克报价为中心的静态研究与模拟练习工作台。

[在线页面](https://yusheng266186-beep.github.io/) · [使用与方法](https://yusheng266186-beep.github.io/README.html)

## 体验与视觉

以“黄金，自有分量”为视觉主题。首屏采用近黑背景、巨幅黄金雕塑、留白与大字号中文，核心金价独立呈现；整站研究工具延续黑金空间：分层透明卡片、深色阅读层、金色细线与清晰的前景数据，保证视觉连续与长时间阅读。黄金雕塑为本地程序构建的三维艺术模型，不代表实物产品或市场数据；无图形加速时使用内置图像工具生成的静态备用主视觉。

页面按五个研究步骤组织：此刻、走势、情景、模拟、研究。雕塑使用持续的 WebGL 三维实体网格，螺旋带具有厚度、倒角和闭合端面。章节切换平滑改变轴向视点，滚动同时控制绕轴旋转、沿轴行进与镜头距离；静止时保持缓慢旋转，指针提供轻微视差。标题与内容分层进入，导航细线与按压反馈保持统一。支持系统减少动态效果、减少透明度、高对比度偏好与键盘操作。

## 界面与阅读节奏

卡片采用 24 / 16 像素圆角层级，控件使用更小圆角，透明度按内容密度区分。数值统一使用本地 Inter 可变字体：金价、权益和情景中枢使用较轻字重，关键数字与数量输入开启等宽数字，图表刻度、时间与明细保持相同字形。字体附带 OFL 许可。

模拟页采用突出总权益的账户总览、四项明细、大号数量输入、费用回执与仓位边界。情景页的周期卡可用点击或方向键选择，选中值与图表中的观察区间同步；此选择不改变行情、因子或账户。研究页将盘面事实与官方原文分开组织；官方资讯支持标题或来源检索、类别筛选及每次五条的分批阅读，保留原文时间，不从关键词直接推断金价方向。章节标题和卡片分层进入；连续切换会取消上一组动画。数值直接显示真实结果，不做伪造中间价格的滚动计数。

## 画面与动效边界

主视觉以已认可的巨幅螺旋金属构图为方向，使用真正的三维螺旋带与物理黄金材质。摄影棚反射随曲面转动，细密拉丝、浅划痕、细小凹点与局部抛光差异补充近看细节，深度遮挡和厚实倒角形成空间关系。渲染尺寸按屏幕像素密度适配（上限 2 倍，并限制像素预算），图形加速或资源加载不可用时回退到静态主视觉。页面不可见时暂停，系统减少动态效果或页面开关可关闭运动。

备用图像的实际尺寸是 1672 × 941；它不限制正常三维舞台的渲染分辨率，也不标为原生 4K 图像。

透明度按内容密度区分：概览与情景卡片透出背景形态；图表、资讯、报告与表格保留更深的阅读底层；输入框局部加深。系统减少透明度时改为实色卡片。

## 数据的时间与含义

- 国内报价链路：东方财富 AU9999 → 新浪 SGE_AU9999 → 部署快照 → 内嵌快照。
- 日线优先读取公开行情，失败后使用上海黄金交易所历史；保留既有有效存档，排序去重。
- 请求成功时间与报价时间分别保存。超过 36 小时、时间缺失或未来时间的报价不会标为实时。
- 分时不可用时，短周期图改用明确标注的真实日收盘序列，不拼接示意曲线。
- 收盘指标使用已记录日线；盘中点单独标记，同日不重复计入历史。
- 跨市场对照需要有效的国际报价、带时间的汇率，且与国内报价处于相近窗口。缺失时停止显示溢价，不使用固定汇率补出结果。
- 新闻源部分失败时保留该来源的旧条目；全部失败则工作流报错并保留原文件。

## 情景模型

情景是可调整的假设，未经过样本外回测或概率校准，不展示置信度或命中率。根据最近 90 个交易日的对数收益计算波动，用每年 252 个交易日换算观察期，再叠加趋势和手动因子对应的漂移假设。区间使用 1.25 倍波动尺度，保持价格为正。

情景卡片与图表使用同一个模型。跨周期图的横轴为平方根时间刻度，图旁明确说明。同周期数据基线保留历史动量及有效溢价信号，其他因子取中性；界面显示手动假设相对该基线带来的中枢变化，不表示预期收益。宏观因子默认中性并标明为手动假设。历史不足 30 点时不生成情景。

## 模拟账户

初始 100,000 元。沿用旧版 `aurum-os-portfolio-v3` 与设置键，保留已有账户。模拟买卖包含价差、手续费和成本；现金与费用精确到分，卖出预览显示扣费后的净收款，部分卖出保留剩余持仓成本。

过期或手动价格需要明确勾选“使用历史 / 假设价格练习”。记录保留交易时间、报价时间及数据模式。界面展示最近 200 笔，CSV 和 JSON 备份包含全部记录。CSV 对公式型备注进行转义；JSON 恢复会校验账户与明细，并要求确认替换。从情景页带入练习时保留观察周期、区间和报价时点，可调整数量；原交易备注不被覆盖，成交后另存情景依据，CSV 同步导出。

本机存储失败时不确认成交；检测到其他页面更新账户时避免覆盖。读取异常账户时保留原始内容，可保存备份后再恢复或重置。止损、止盈是自设参考，不会自动下单。本项目没有真实账户和真实交易接口。

## 自动更新与部署

市场快照每 15 分钟尝试更新，历史日线每个工作日更新三次，资讯每两小时更新。所有刷新任务共享并发组，避免数据提交互相覆盖。部署同时响应 main 更新和数据刷新成功事件，解决机器人数据提交未触发普通 push 部署的问题。

全部市场源失败或返回过期无效报价时，任务失败且保留旧文件；页面继续如实标注其时间。GitHub 定时调度属于尽力运行机制，页面仍需依据实际报价时间判断时效。手动更新可在 Actions 中运行对应工作流。

国际参照是可选项。若配置环境汇率，需同时提供 `USD_CNY` 与 ISO 格式 `USD_CNY_ASOF`，超过 72 小时不用于比较；页面还要求国际与国内报价在 8 小时窗口内。默认不设置汇率。

## 结构

- `assets/core.js`：无 DOM 的报价校验、历史、情景、账户及 CSV 计算。
- `assets/scene.js`：章节路由、导航、内容显现与交互反馈。
- `assets/gold-geometry.js`：有厚度、倒角与端面的三维螺旋几何，及轴向镜头轨迹。
- `assets/gold-surface.js` / `assets/gold-worker.js`：后台生成并传输网格与材质数据，减少首屏主线程阻塞。
- `assets/render-policy.js`：高刷新率绘制节奏、像素预算与持续压力调节。
- `assets/gold-world.js`：三维金属渲染、摄影棚反射、阻尼镜头、像素密度适配与动效生命周期。
- `assets/app.js`：数据源适配、缓存、视图、图表、设置与报告。
- `assets/styles.css` 与 `assets/cinematic.css`：工具布局、组件与黑金视觉主题。
- `assets/fonts/`：内嵌字体与原始许可证；`mark.svg` 为自绘标识；`assets/gold-sculpture-master.png` 为细节修订后的主视觉（1672 × 941），原始版本仍保留；两者均由内置工具生成，提示词见 `docs/VISUAL_ASSETS.md`。
- `scripts/`、`tests/`：数据更新、来源完整性检查和回归测试。
- `jianwei/`：同仓库的独立项目，本次保持原样。

详见 [架构说明](docs/ARCHITECTURE.md)。公开行情可能延时，情景和模型笔记均用于研究与虚拟练习。

### 滚动稳定性

雕塑以最多 60 次/秒绘制，并按像素预算及持续帧压力调整采样密度。固定舞台使用稳定视口高度，画布仅在尺寸实际改变时重建一次缓冲。卡片保留透明深色渐变，移除对实时背景的多层模糊与滚动整卡淡入，因子滑杆和图表交互合并为每帧一次更新。

驱动假设默认收起为摘要控制台；展开后按盘面与情绪、供需与汇率、全球宏观分组，一次只显示三个参数。支持键盘切换，切组保留假设值。

### 观察与复盘

情景图下方可记录当前观察周期，保存当时的主价、报价时点、情景区间、全部因子与选填理由。在研究页的观察手记中可展开查看、导出或恢复 JSON、移除或撤销移除，也可按当前报价重新载入一组旧假设。记录保存在本浏览器，最多 50 条；默认显示最近三条，其他按需展开。旧记录不随新报价改变，报价变化不作为情景准确率。恢复备份时合并有效记录并跳过重复项，同编号内容冲突、容量超过 50 条或写入失败时不覆盖原记录。撤销移除后仍按原创建时间排序；报价刷新保留展开状态和键盘焦点。

手动调整的因子在本次页面中保留，行情轮询不会覆盖；“恢复数据基线”重算历史信号并归零其他假设。研究上下文与本地摘要使用当前选择的观察期。已生成的外部报告在输入变化后保留，并明确提示重新生成。公开来源目录按需展开，页脚入口直接打开目录。

本地研究笔记按盘面、持仓、情景、消息四个主题整理不同内容。外部报告生成期间保留生成状态，输入变化不会插入另一份本地摘要。页内链接支持直接打开、刷新及后退，保留目标章节并展开相应目录。
