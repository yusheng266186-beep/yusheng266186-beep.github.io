# AURUM 国内黄金决策终端

面向国内黄金市场的实时行情、历史分析、情景预测和虚拟交易看板。

## 在线访问

部署完成后访问：

https://yusheng266186-beep.github.io/

## 主要功能

- 国内黄金价格统一使用人民币/克展示
- 上海黄金交易所行情校验与国内市场因素分析
- 历史走势、波动率、技术指标和多周期情景预测
- 一周、一个月、半年、一年及更长期观察框架
- 虚拟买入、卖出、持仓成本和盈亏分析
- 无需大模型 API 即可使用核心行情与分析功能
- 可选 OpenAI 兼容模型接口，仅用于辅助决策建议
- GitHub Actions 定时刷新市场快照、历史行情和官方资讯

## 数据说明

网页优先使用国内市场数据，并在界面中展示数据来源、更新时间和校验状态。行情可能受到交易时段、官方延迟、网络可用性和数据源维护的影响，页面提供缓存与降级机制。

## 风险提示

本项目用于市场研究、教学和虚拟交易，不构成任何收益承诺或投资建议。黄金价格会受到人民币汇率、国内供需、全球利率、地缘风险、央行购金及流动性等多种因素影响。
