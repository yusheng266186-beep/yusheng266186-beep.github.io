# 见微 · 学情研究台

**从每一道题，看见每一次成长。**

从零建立的浏览器学情研究工作区。以教学任务组织九个独立入口，采用暖白、森林绿、蓝与陶土色的界面，以及 SVG 图表和短距切换动画。各模块分别保存自己的选择，不设强制贯穿所有分析的班级、类别筛选。

线上入口：https://yusheng266186-beep.github.io/jianwei/

## 工作方式

| 入口 | 研究对象 | 主要内容 |
| --- | --- | --- |
| 年级研判 | 考试 → 类别、届别 | 总分结构、达线、班级位置、成绩分布、学科有效率 |
| 有效达线 | 当前考试 → 对照考试 | 总分与人数任务、增量、英语/日语、学科有效、双上线、10/20分临界带 |
| 一卷透视 | 班级 → 单场考试 | 实际选科、原分/赋分/排名、特控/本科分差、化学+生物分差、同类比较 |
| 纵向对照 | 班级 → 自选多场考试 | 共同参考学生、均分/有效率/人数/分差/学科趋势、逐人矩阵与分位 |
| 逐题研究 | 学科 → 考试 → 观察范围 | 学科表现、逐题均分/得分率/失分/区分度、知识点行动、班级/学生热力图 |
| 个人轨迹 | 学生 → 观察考次 | 跨班历史、阶段趋势、各科学科轨迹、原分/赋分/排名/分差、全部小题 |
| 临界行动 | 目标层次 → 距离与方向 | 临界名单、短板、最近突破学科、教师记录与完成状态 |
| 报告工坊 | 报告类型 → 独立范围 | 年级/班级/个人/试卷报告、教师判断、Word、Excel、打印/PDF |
| 数据书房 | 文件与本机配置 | Excel/CSV/JSON 导入、字段对应、追加/替换、备份、班级任务、有效线、题库 |

## 使用真实成绩

默认附带从高2024级质量复盘标准表提取的**匿名成绩样本**，保留成绩、历史、有效线、班级任务与逐题记录；不包含真实姓名、身份证号码或原始工作簿。

点击“导入原表”，选择标准版成绩工作簿。姓名、班主任和任课教师仅在本浏览器工作区恢复。后续补充小题或新考次使用“追加考次 / 补充小题”。小题工作簿可单独上传，按考试、班级、姓名、学科联结。

“数据书房”提供空白录入模板、完整 JSON 备份、CSV 字段对应、原项目 GradeDataset JSON 适配、班级任务与任课信息编辑、考次名称/顺序/排名范围配置、总分及学科有效线、题目满分与知识点编辑。

导入和分析均在本机执行，数据存储于 IndexedDB；筛选偏好与行动记录保存在 localStorage。不会向 GitHub、服务器或外部分析服务上传原始成绩。备份可迁移到其他设备。

## 数据与口径

- 四类展示表对应的功能由“学生基础”、有效线、班级任务、教师信息与学科原始小题重新组织，不读取当前筛选后留下的单人/单班展示缓存。
- 17班是物理类补习班，18班是历史类补习班；应届与补习分别观察，选科按学生实际记录展开。
- 日语按学生的语种记录处理；英语与日语不混作同一小题科目。9班使用地理成绩与地理题库。
- 原分与赋分分别保留；缺失值不当作0，0分有效；不由学科成绩推算缺失总分。
- 总分上线与学科有效采用每名学生所属考试、类别的对应线。双上线表示总分与该学科同时达到同层次有效线。
- 原表中带星号等不明确的题目满分保留空缺，逐题得分原样保存；不以最高观测得分推算满分。
- 区分度采用学科小题总分最高与最低两组的均分差除以题目满分，分组默认各27%，可编辑。
- 跨考次保留原排名统计范围；同类分位按当次同类别、同届别的本站学生计算。
- 纵向共同参考口径采用选定考次的学生交集，不自动填补缺考记录。

## 工程结构

无需构建，原生 ES Modules 直接在 GitHub Pages 运行。

| 文件 | 职责 |
| --- | --- |
| index.html / styles.css | 页面壳、响应布局与动画 |
| src/model.js | 新的数据结构、统计与口径 |
| src/ingest.js / import-worker.js | 原表、通用字段、旧 JSON 导入与后台读取 |
| src/store.js | 本机数据与独立模块偏好 |
| src/charts.js / ui.js | 原生 SVG 图表、热力图与界面组件 |
| src/export.js | Excel、Word、打印与图表导出 |
| src/views/ | 九个任务模块 |
| src/app.js | 路由、交互、导入与教师记录 |
| data/sample.json.gz | 匿名原表样本 |
| vendor/ | SheetJS、JSZip |
| docs/ARCHITECTURE.md | 模块、联结与发布说明 |

使用任意静态 HTTP 服务打开即可，例如 python -m http.server 8000。需要支持 ES Modules、IndexedDB、Web Workers 与 DecompressionStream 的现代浏览器。
