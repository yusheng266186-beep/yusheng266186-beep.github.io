# 新工作区的结构

见微是独立实现，旧质量慧析仅用于了解数据格式、班级资料和功能范围。页面组织、路由、数据层、组件、图表、视觉与动画均重新编写，没有继承旧项目的 React/Next 架构或界面代码。

## 每项研究有自己的起点

年级研究的起点是考试与群体，班级研究的起点是班级，试题研究的起点是学科与试卷，个人研究的起点是学生。筛选偏好分别存储在 view:overview、view:classroom 等命名空间。导航不会将一个模块的类别或班级强制作用于其他模块。跨模块跳转只为明确的目标带入必要参数，例如点击姓名打开该生该场考试。

## 数据关系

- Student：本机学生身份、姓名。
- Score：考试、身份、实际班级、类别、语种、总分与学科原分/赋分/排名。
- Exam：考次代码、显示名称、时间顺序与排名范围。
- Line：考试 × 类别的总分和学科有效线。
- Profile：班级类别、届别、班型、任课信息与人数任务。
- Bank：学科 × 考试的题号、明确满分、原始满分文字与知识点。
- Answer：考试 × 班级 × 学生 × 学科的逐题得分。
- Action：学生、目标考次、层次、突破学科、教师记录与完成状态。

原表学生身份按姓名联结，保留每次考试实际所在班级；因此转班不截断个人历史。相同考试、班级、身份的后导入记录替换先导入记录。学校成绩工作区中如有同名学生，需在导入原表使用一致的姓名区分标记。

## 与四类工作表的关系

| 原表 | 新工作区 |
| --- | --- |
| 班级有效人 | 有效达线的总分/任务、英语/日语、对照增量、临界累计区间、学科有效/双上线 |
| 个人学科小题得分 | 逐题研究与个人轨迹的原始小题、知识点、历次学科和成绩联结 |
| 班级多次考试对比 | 纵向对照的独立考试集合、共同参考口径和全员逐科明细导出 |
| 班级成绩分析单次 | 一卷透视的成绩/原分/排名/分差，以及化学+生物本科分差 |

展示表缓存只用于理解字段意义。运算直接使用基础记录，不依赖工作簿保存时选中的班级或学生。

## 本机运行

1. 原表由 Worker 和 SheetJS 读取。
2. 导入层转换成统一结构；规范化按稳定键合并记录。
3. IndexedDB 保存工作区，模块偏好和行动记录保存在 localStorage。
4. 统计层按明确上下文计算，不隐式读取全局筛选。
5. 模块生成语义 HTML 与 SVG；事件由应用层处理。
6. 报告、Excel、Word、SVG、PNG 在本机生成；PDF 使用浏览器打印。

匿名样本由委托人提供的标准工作簿提取并压缩。公开文件中没有姓名、身份证号码、任课教师姓名或原始工作簿。浏览器所需的 XLSX 与 ZIP 依赖放在本项目内。
