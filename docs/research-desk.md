5.1.0 把研究页升级为证据与条件观察工作台：从已闭市价格计算区间、均线、真实波幅与回撤；把偏支持、偏压制及未判定的市场输入分开展示，每条保留观测、可用时间及原文。日级数据只显示日期，资讯采集时间与研究整理时间分开，过期状态明确保留。

可以调节美元金价、人民币汇率和内外盘参考差做算术压力测试，包含金价与汇率交叉项。它是条件假设，不是目标价。可保存上沿突破、下沿失守或自定义收盘条件，冻结锚点、触发价、失效价、依据和当时解读；后续只统计保存之后的5/21条已闭市记录，盘中触及不算确认。首次到期或失效结果保留，历史修订另行提示；支持复盘备注、CSV、JSON备份恢复和撤销移除，原情景手记与模拟账户不迁移、不覆盖。

服务端以 CodeBuddy DeepSeek V4.1 Flash 生成带证据引用的研究解读。只发送精简的公开市场数据，不发送本机账户、观察或备注；密钥通过 GitHub Actions Secret 注入，不进入网页。引用缺失、已识别方向冲突、目标价、概率、买卖指令和强因果条目不展示；仍不能证明所有模型推断都正确，须回到原文核实。可用条目不足时保持完整的结构化研究功能。

模型研判最短间隔30分钟，每个窗口最多调用一次；新增消息、正文补抓和积压均不触发即时追加，失败及手动刷新同样遵守间隔，跨北京时间零点也不重置等待。每日调用次数不另设上限。等待期间行情、新闻与原文采集继续运行；待处理内容留存至下一窗口，每次最多8条新增或变更消息与2条已审阅上下文，兼顾最新消息与最早等待内容。已有有效审阅按指纹复用，无变化时不空调用，实际调用与用量继续记录。采集仍目标每5分钟、页面每分钟核对，实际依赖 GitHub 调度与源站，不能保证逐笔实时。复用工作流通过 [GitHub 的 secrets inherit](https://docs.github.com/en/actions/how-tos/reuse-automations/reuse-workflows) 接收仓库密钥。

本次没有提高收益的宣称，也没有替换线上预测内核。已完成的 CodeBuddy 预测试验及所有历史封存结果保持不变；条件观察是个案研究，不计为无偏模型胜率或交易收益。

## 可复算的价格与条件

- 使用采集时点已知、交易日已闭市的记录；最近60条提供价格上下文。均线按20/60条收盘算术平均，区间按最近20条高低价，真实波幅采用最近14条 max(高-低, |高-前收|, |低-前收|) 的均值。
- 默认上沿/下沿分别取本次窗口高低价；失效参照为冻结的20日均线。极端重合时仅调整至边界相反侧，表单允许自行修改。条件不代表建议下单。
- 压力测试：国际金价 × 人民币/美元 ÷ 31.1034768 + 内外盘参考差；两项百分比变化相乘，保留交叉项。参照来自日期级存档，参考差含错时与规格差异，不当作可交易同步溢价。
- 观察窗口只计保存之后的未来收盘，站上用严格大于、跌破用严格小于。首次触发后再检验失效条件；未触发到期、触发后到期及触发后失效分别记录。结果不计算策略收益，不把自选条件汇总为模型准确率。
- 每条观察连同公开依据、当前参数和用户理由保存。首次终态结果不覆盖；来源历史修订时保留原结果并提示重新核对。JSON恢复只合并相同冻结记录，冲突不覆盖。

## AI 的核对边界

数值事实与方向标签先由程序生成，再交给模型解读。引用检查能识别缺失来源，有限规则能识别人民币汇率、美元代理、实际收益率、原油和已记录金价的部分方向冲突；这不是完整的事实核查或因果验证。界面保留“模型解读”身份，不把它混入原始数值记录。引用到原文也不等于报道已被多方证实。

最新模型输入是最多23条按相关性挑选的公开依据与已计算价格结构，不再每次重读完整历史。输入中没有账户、成交明细、本机观察或备注；用户主动配置的自定义外部接口使用其原有上下文方式，与服务端缓存研究分开。

本地生成：`node scripts/build-analysis-desk.mjs`；可用环境密钥为 `AURUM_CODEBUDDY_API_KEY`。`--refresh-ai` 用于人工运维联调，仍受每日12次上限约束；正常调度不使用这个参数。公开页面不具备直接触发收费请求的接口。发送后超时不自动重试，调用开始前先写用量记录。

## 预测试验为什么没有直接上线

2026-10-25 CodeBuddy 实验事先固定25个历史截止日及两种输入。DeepSeek共同有效23个起点，纯数据7/30日MAPE为1.421%/3.493%，同起点持平为1.402%/3.458%；Kimi共同有效24个起点，纯数据为1.411%/3.523%，同起点持平为1.370%/3.370%。加入公式或有界建议仍未稳定胜出，主要候选对线上模型的配对区间包含零。GLM缺少两臂共同有效结果，不能据此判断方向能力。

历史同期外部消息档案不足，因此这批结果主要说明量价回放表现，不能证明实时消息没有价值，也不能证明模型未来能提高收益。实验保持封存，本功能改进研究流程而没有根据这些已见结果重新调价格参数。
