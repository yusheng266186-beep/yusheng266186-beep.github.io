# 外部方法研究与候选模型：4.6.0

本轮研究不是“公开模型准确率可以直接移植到黄金”的承诺。我们实现了两个可重复候选，和现有模型、持平预测在同一批 AU9999 人民币/克日线对照。两个候选未通过预先固定的采用门槛，因此默认预测保留，网页开放候选回放与并行记录。没有在看到尾段结果后继续调参。

## 公开研究与取舍

- [世界黄金协会 GRAM](https://www.gold.org/goldhub/tools/gold-return-attribution-model)：参考其驱动因素分组。它用于历史收益归因，不把解释过去视为已经证明能预测未来。
- [Amazon Chronos-2](https://github.com/amazon-science/chronos-forecasting)：参考多变量、外生输入和分位预测设计。通用基准成绩不代表 AU9999 成绩；本轮没有下载、运行或部署其预训练权重。
- [Google TimesFM](https://github.com/google-research/timesfm)：研究外生变量预测。未运行权重；3.0 权重与源代码许可不同，且预训练历史的金融数据交叠不能作为本项目无泄漏检验。
- [黄金 ARIMA / XGBoost / LSTM 对照项目](https://github.com/LouSens/gold-price-forecast-arima-lstm)：参考收益率重构、按时间切分和持平对照。其报告中复杂模型对次日持平基准的增益很小，不能只看价格层面 R²。没有复制其实现。
- [XGBoost 论文](https://arxiv.org/abs/1603.02754)：借鉴浅层残差提升与正则化。本项目是自行实现的 12 棵深度一残差树，不冒称运行了 XGBoost 库。
- [另一个黄金项目](https://github.com/HuguitoH/gold-forecast)标注 98.2% Accuracy，但其说明的测试窗口仅 40 天。此数不能当作本项目涨跌方向命中率，也没有纳入我们自己的成绩。

这些来源提供方法线索，不构成对任一模型未来准确率的保证。

## 候选计算架构

1. 目标为各周期完整的未来对数收益，按每年 252 条记录交易日换算 7/30/180/365/1095 自然日；不强行拉开中枢，也不把美元/盎司预测直接当作人民币/克。
2. 价格特征包含 1/5/20/60 日收益、均线偏离、回撤、波动变化、闭市高低区间、开收变化、同来源量能和下跌日比例。
3. 直接周期岭回归使用最多 756 个历史起点；只有目标已经走完的样本参加训练。缩放只在训练样本内拟合，标准化截至 ±4；固定系数惩罚 40、截距惩罚 10，时间半衰期 252 条记录。
4. 浅层提升在岭回归残差上训练 12 棵深度一树，固定学习率 0.1、训练分位切点 20/40/60/80%、叶子至少 10% 权重；无尾段搜索。
5. 在线集成保留持平、线性、非线性三个专家，初始权重 40/30/30%。只根据此前已完全到期的 24 个不重叠目标的标准化误差更新权重；不足 8 次结果时保留初始权重。没有用当前预测的未来真实价格选择当前权重。
6. 区间使用 EWMA 波动与此前 40 个完整目标的误差分位校准，先预热 8 次；不足时明确显示未经充分检验。历史覆盖率不等于未来概率。
7. 外部特征只从起点以前已采集、已发布的档案读取。单通道不足 60 个有效训练行、或覆盖不足 60% 时不拟合系数；缺失均值插补只在训练标准化后使用，不把缺失当成观测零。

主模型与试验模型分开。试验中枢不驱动交易、不改写默认路径。每日后台同时冻结当前模型和在线集成预测，只有到期后追加核验结果，不改写原中枢。新算法标识与旧版记录分开。

## 实时采集与覆盖边界

本轮实采 6 个市场来源、9 个数值因子：ECB 人民币/美元和美元/欧元代理，Treasury 实际收益率、2 年名义利率、10减2年利差及同日名义减实际收益率通胀近似，Cboe VIX，EIA/FRED 原油，CFTC 管理资金黄金净头寸占比。

- [Treasury 官方 XML 说明](https://home.treasury.gov/treasury-daily-interest-rate-xml-feed)
- [EIA 原油经 FRED 分发，按其要求注明来源](https://fred.stlouisfed.org/series/DCOILWTICO)
- [CFTC COT 说明](https://www.cftc.gov/MarketReports/CommitmentsofTraders/AbouttheCOTReports/index.htm)

利率相关通道按组限额，避免重复放大。短端名义利率、原油、期限结构、通胀近似与头寸拥挤为监测输入，不预设永远利好或利坏；有足够档案后才可学习系数。当前档案短，外部通道尚不能获得可靠拟合系数。现有实时方向修正仍是封顶、衰减的规则先验，不伪称已验证的因果关系。

政策、央行购金、ETF 资金流、地缘、流动性和供应通过明确事件接入，保留原文/来源/发布与首次采集时间、否定和条件过滤、去重与衰减。ETF 持仓与央行储备的稳定数值序列尚未接入；页面明确显示缺口。公开文件格式不符时拒绝解析，不能把 PDF 当 CSV 读入。

后台以每五分钟运行、页面每分钟核对为目标；源站有自身发布频率，CFTC 是周度数据。首次采集时间与观测日期分开，旧观测不会因刷新变成新数据。GitHub 调度和源站都可能延迟，失败保留带原时点的数据与失败状态，不承诺逐笔实时。

## 固定检验

冻结 1,799 条闭市日线，2019-05-27 至 2026-10-23；数据、代码 SHA-256 写入 plan.json，kernel/ 保留代码。开发段截至 2022-12-31，验证段为 2023–2024，最后时间段为 2025–2026-10-23。跨段目标剔除。

每周期起点为第 119 条后按目标长度依次推进，首 8 次到期用于预热。三模型共 1,194 条校准后的对照记录，384 个不同截止日。样本数随周期变化；长期完整目标很少。

采用门槛在结果产生前写入：开发与验证各至少 12 个非重叠目标、MAPE 相对现有模型降低至少 2%、RMSE 比不超过 1.02、方向退化不超过 3 个百分点，并控制有足够样本的分行情退化；还须优于持平。锁定选择后再看最后段，要求改善至少 1%。

本轮两个候选均未通过开发/验证，所以不采用。完整失败原因保留在 selection.json；最后段仍公开两者结果用于诊断，不据此重新选型。

| 1 周 | 2.85% | 2.87% | 2.82% | 2.76% | 86 |

更复杂并未稳定更好。以上历史曾用于此前开发，最后段只是本轮按时间保留的研究尾段，不是从未见过的“干净样本外”。历史价格是当前快照，也不是逐次修订版本。

旧日期没有当时已采集的宏观/新闻档案，本轮只验证量价/OHLC，不能声称验证了假想的历史实时新闻效果。刚新增的外部通道需要今后真正到期的记录检验。

## 复现与回放

在项目根目录、Node 22：

```sh
node scripts/evaluate-research-model.mjs development --reproduce
node scripts/evaluate-research-model.mjs holdout --reproduce
node --test
```

复现只比较封存结果，不覆写。网页“模型实验室”可切换分段、下载所选周期三模型的全部 CSV；“历史回放”可选择当前/在线集成/浅层提升并指定日期，后续价格只参与核验。示例取最后段的首、中、末起点，没有按误差挑选。
