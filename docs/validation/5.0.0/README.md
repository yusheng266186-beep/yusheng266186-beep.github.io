# 五方向架构 · 固定检验 5.0.0

本轮完成架构与功能，不声称预测能力已经全面提高。新增三部分分解、观测修订归档、结构化事件/预期配对、周期与状态专家、经验概率和费用筛选，并统一后台发布。默认模型保持原计算方法，完整新架构仍为研究候选。

## 数据和计算

国内参考关系为：国际现货美元/金衡盎司 × 人民币/美元 ÷ 31.1034768，再加国内参考差。国际是新浪 XAU 现货，汇率主来源是 ECB EUR 交叉参考，新浪 FX 作备用。日线有不同市场时点，参考差含错时、规格、来源差异，不是可交易同期溢价。国际日线与汇率在历史价格快照诊断中统一滞后至次日 UTC08:00；当前日未完成条目拒绝存入。

观测版本只追加，strict 外部输入只选截止日前已采集或官方可用的版本。国内日线在两种模式中均为当前历史价格快照，并没有当年逐点修订档案；不能将“严格外部档案”理解为所有历史价格都具有当时版本。snapshot 只用截止日以前的滞后价格，但历史价格是今天下载的版本；它不能冒充当时已知档案。ALFRED 导入已实现，可选 FRED_API_KEY，目前没有配置，历史宏观修订数据没有导入。新闻版本保持发布和首次采集双时点。

四专家为持平、衰减趋势、均值回归和三部分分解。趋势/震荡/冲击是过去收益与波动的软权重，不是对未来的已知分类。专家权重使用此前已到期、不重叠误差。分解当时缺失就不参加；不能把缺失当作持平专家的成功记录。宏观残差回归至少60个不同有效观测日、80个已到期训练行。新闻事件反应至少12个同类不重叠到期事件，当前不足，不伪造训练后价格影响。

事前数值预期提取仅接受指标、月份、单位明确且带明确未来发布日期的报道，必须已在公布前抓到。发布后的报道即使含“预期值”也不形成事前预期。没有可信配对则保持缺失。当前通用关键词事件可结构化，数值配对和反应系数尚待积累，不能声称已经验证新闻增益。新增数值提取层在封存价格实验后完善；封存输入和内核没有修改，旧日期仍没有可用的事件档案。

概率基于过去最多100个完整目标的标准化残差，至少20个结果，使用Beta(2,2)收缩方向频数并输出Q10/25/50/75/90。新分解/事件/宏观域须另积累20个真实到期目标，否则只显示未接新域候选的经验概率，并明确试验状态。费用筛选使用单边手续费和完整买卖价差计算往返门槛，不下单。

## 实验设计

协议在结果前固定，见 protocol.md。1,799条国内日线，2019-05-27至2026-10-23；冻结输入和内核哈希见 plan.json。开发截至2022，验证2023–2024，尾段2025–2026-10-23。跨段目标剔除，先预热20个非重叠完整目标，起点252后每5或21条记录推进。长期目标太少，不能以外推代替准确率证明。

四个固定消融（完整、移除分解、移除状态、移除事件）×两种输入模式，现有模型在同一批起点单独重算。总3,042条模型/模式/周期记录、327个不同截止日，不是3,042个独立样本。每项指标使用其周期的不重叠目标数。价格此前已用于研究，因此尾段不是从未见过的干净样本外。

| 严格档案尾段 | 新架构MAPE | 同起点现有MAPE | 持平MAPE | 新架构Brier / 历史频数Brier | Q10–90覆盖 | 目标数 |
|---|---:|---:|---:|---:|---:|---:|
| 一周 | 2.302% | 2.354% | 2.309% | 0.254 / 0.251 | 73.26% | 86 |
| 一个月 | 6.802% | 6.334% | 6.683% | 0.243 / 0.233 | 55.00% | 20 |

周度价格误差略改善，但概率评分没有优于历史频数基准；月度误差和覆盖都不够好。开发/验证固定门槛未通过，完整新架构不替换默认预测，没有根据尾段再调参。不能将概率数值当作已被证明可靠的未来命中率，尤其月度经验区间覆盖明显不足。尾段每组起点不同于4.6实验，因此不能直接跨实验比较MAPE优劣。

严格历史档案没有旧日期的分解或新闻，移除这些项的结果相同，说明没有历史输入可以检验，不说明这些因子无效。价格快照诊断另外报告；尾段分解快照周度MAPE2.292%、月度6.964%，不作为替换默认的证据。当前来源可能修订，这些诊断不具有实时档案的证据强度。

## 文件与复现

- plan.json / protocol.md：事先规则、时间划分、采用门槛和数据/代码哈希。
- frozen-inputs.json / kernel/：原始冻结输入和原计算内核。
- development.json / selection.json / holdout.json：全部成功与失败结果、相同起点比较、消融、Brier、分位损失、覆盖/宽度和含费用研究信号。
- data/system-validation.json：网页摘要。失败原因公开，不由实时消息改写。

运行 `node scripts/evaluate-system.mjs development --reproduce` 与 `node scripts/evaluate-system.mjs holdout --reproduce`。已封存结果不覆写，复现差异即失败。首次预检曾修正陈旧新闻衰减按发布时间而非首次抓取时间计算的错误，修正前草稿仅本地保留，未参与选型；此最终内核和性能结果之后没有调参。

后台每天冻结闭市起点的默认、在线集成、完整架构、未接分解候选，后续只追加到期结果。Brier与分位损失仅在当初确实发布相应概率时计算。每日起点可能重叠，应与独立回测分开看。
